Implementation status ​

This is a map of the 57d53c0 baseline, not a claim about unmerged branches, installed runtime versions, or all planned milestones. GitHub owns live issue and PR state; the project tracker holds current assignments and acceptance evidence.

Implemented in this baseline ​

AreaCurrent supportBoundary
Pi DurableConversations, extensions, tools, documents, SQLite, retry wiringMac effects still require guards and replay handling
Computer-use v2Observe/act/finish, task state, async progress, plans, budgets, success checksEnabled only when CARET_CU=v2
Action validationClosed shared action and shallow-composition predicate schemaInternal types can express more than model-facing JSON

Secret tasksUser/handoff modes, screenshot/record suppression, masking, cleanupGeneral encryption and arbitrary sensitive forms remain outside this support
RecallOpt-in local task recallRetrieval, not weight training

Representable, proposed, or incomplete ​

  • Correction records: a schema and type exist; automatic live veto/undo/takeover capture is not wired here.
  • Shadow and teach: allowed record sources and design material exist; they do not establish continuous human capture.
  • Predicate DAG and commit events: record schemas describe these; current task/step writers leave their relevant fields empty or null.
  • Native caret-direct actions: focus_target, read_context, select_range, and insert_at belong to later design/spike work, not the current action union.
  • Universal worker/plugin registry: a tracker proposal, not the existing backend definition mechanism.
  • General encrypted sensitive-document storage and training consent pipeline: separate work; neither follows from secret handoff or include_in_training existing as a field.

Historical documents ​

computer-use-spec.md describes intended semantics alongside milestones. SCHEMA_LITE.md describes a broader representation and build plan. wave2-plan.md and wave3-plan.md preserve decisions and sequencing. schema-lite-notes.md is a dated implementation note: for example, its warning about secret recording predates the current secret-task suppression code.

Use those sources for rationale. Use the current declarations, validators and writers for current support. The source catalog provides a reading order without copying historical documents into another canonical version.
