On this page

Understand Caret from the inside ​

Caret is a Mac supervisor agent. A Letta supervisor routes requests to background tools or a Pi computer-use worker; a native helper observes and acts on the visible Mac. This guide explains how those pieces fit together and which contracts the current code actually implements.

Choose a reading path

New to Caret? Start with the system map, then workers.

Reviewing the agent loop? Read the Pi Durable harness and execution boundary.

Writing an integration or analyzing data? Start at the contract map, then inspect the generated type and schema reference.

Current implementation, with boundaries ​

The narrative was checked against repository baseline 57d53c0 on October 16, 2026. Generated references are extracted from the checkout at build time. They preserve source comments, which can include historical milestone names; the implementation status explains how to interpret them.

Schema support is broader than production coverage: a correction schema does not establish a live correction-capture workflow, and a durable conversation does not make a Mac click exactly-once. Those distinctions are explained beside the relevant contract.
