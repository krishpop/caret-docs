JSON record schemas ​

Extracted from the current checkout. Source links navigate current main; SHA-256 identifies the extracted bytes, which may differ from main. Source comments describe the declarations; see the contract map for runtime boundaries.

The record validator uses Ajv draft 2020-12. Tables summarize top-level properties; the full JSON blocks specify nested required fields, formats, enums and extension rules. Schema support does not imply the runtime populates every field.
