02 / Keep the nouns straight
Three layers. Two runtimes.
A provider library is not an agent loop. A transport is not a durable log. A helper action is not a model generation.
Provider access
pi-ai
Builds the provider-facing stream. Events may contain text, reasoning, or partial tool arguments. A chunk is not necessarily one token.
Agent execution
Pi vs. Pi Durable
Pi coding-agent runs a loop over a session’s active JSONL branch. Pi Durable runs persisted generation and tool tasks over durable conversation state. Caret’s Mac worker uses the latter.
Orchestration + interface
Letta + Caret
Letta owns the supervisor’s routing and memory. Caret forwards supervisor prose and sampled worker progress to its native command bar. They are not one shared model stream.

03 / Better by design
Make the contracts
as clear as the pixels.
Recommendations—not claims about the current implementation. Optimize observability and cancellation before making irreversible actions more “live.”
Proposed engineering work


P0 / SAFETY
Cancellation should be a protocol.
A shorter main-thread block is a mitigation, not a cancellation architecture. A stop request and a stopped side effect are different facts.
Engineering move + trade-off
Change: use a cancellation-aware insertion state machine, schedule waits without blocking the event loop, and keep AX/AppKit calls on their required execution context. Recheck target binding and stop state between chunks; return applied range, read-back state, and partial/unknown outcome.
Trade-off: a user may move focus or edit between writes. More responsive cancellation means more interleavings to validate.
Acceptance: cancel at every chunk boundary; prove no subsequent write is admitted after cancellation is acknowledged. Never claim to undo text already inserted.


P0 / SAFETY
Persist intent. Reconcile effects.
Safe replay is explicit. A durable tool record does not make an external text insertion exactly-once.
Engineering move + trade-off
Change: retain operation ID, expected app/window, starting selection, and outcome. After interruption, read the field before retrying; use hashes or redacted metadata rather than storing sensitive draft content unnecessarily.
Trade-off: reconciliation costs reads and cannot always identify a unique result after user edits.
Acceptance: crash between write and acknowledgement. Recovery must report partial/unknown or prove completion; never duplicate the insertion blindly.


P1 / OBSERVABILITY
Name streams by what they mean.
A single “text” label hides origin, identity, and finality. Keep supervisor prose, worker progress, and model diagnostics distinct.
Engineering move + trade-off
Change: introduce a typed envelope carrying trace, task/conversation, generation/message ID, origin, event sequence, and payload semantics (delta, snapshot, terminal). Expose Pi diagnostics in a separate optional pane, not as supervisor speech.
Trade-off: versioning and privacy filtering become first-class work. Not every reasoning stream should be displayed or retained.
Acceptance: interleave two tasks and two supervisor messages; reducers must not mix text, regress state, or assign progress to the wrong request.


P1 / RESILIENCE
Reconnect to state, not hope.
The in-memory SSE hub does not replay missed events. Reopening the socket is not the same as restoring the interface.
Engineering move + trade-off
Change: add a snapshot handshake and sequence watermark; then either bounded event replay or monotonic snapshots. Deduplicate by stream identity and sequence, and retain enough terminal state to settle a disconnected UI.
Trade-off: retention, redaction, and race-free snapshot/replay ordering add complexity. Persisting every token is not required.
Acceptance: disconnect immediately before completion; reconnect and show the correct final state once, without a duplicated or resurrected card.


P1 / CONFIGURATION
One policy. Runtime-specific adapters.
Keep Letta and Pi separate, but centralize per-role provider/model selection so a provider migration cannot silently leave auxiliary callers behind.
Engineering move + trade-off
Change: a shared configuration resolver for supervisor, computer use, routing, extraction, and explicit fallback. Adapters validate support and report desired versus actual models, including persisted conversations and deployed revision.
Trade-off: model IDs, modalities, and protocols differ. Native Radius support in Pi does not establish Letta compatibility.
Acceptance: fail clearly for unsupported mappings; inspect every enabled caller and prove which provider receives each role’s requests.


P2 / RESEARCH
Stream drafts before external actions.
If composition latency matters, first stream into a local preview. Live tokens going directly into another app are a new side-effect protocol.
Engineering move + trade-off
Change: preview → finalize → insert using today’s completed argument. Explore external draft streaming only with target binding, operation ID, acknowledged offsets, revision handling, cancellation outcomes, and an explicit finalization boundary.
Trade-off: provisional text may be revised, user edits may collide, and some fields auto-submit. A smoother animation can increase actual risk.
Acceptance: retries, revised text, partial cancellation, focus changes, and auto-submit fields. Never infer permission to send from permission to draft.
